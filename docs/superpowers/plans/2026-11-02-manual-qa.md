## Dev stack

1. `cd server && cp .dev.vars.example .dev.vars` and set `AUTH_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, and a Turso URL (remote `libsql://…` or a local file for the Bun harness).
2. `bun run --cwd server dev` (Wrangler on 8787). For a file-backed local run without Wrangler: `bun run server/scripts/serve.ts`.
3. `bun run dev` (Vite on 8080, proxies `/api` to 8787).
